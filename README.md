# Creative Studio – Digital Agency Website

A modern and responsive digital agency website built using Next.js and React. Creative Studio showcases digital services, creative projects, and contact information through a clean and elegant user interface.

## Project Overview

Creative Studio is a digital agency homepage designed to present creative services and portfolio projects in a professional way. The website features a modern black and gold theme with a responsive layout.

## Features

- Modern and attractive homepage
- Responsive navigation bar with mobile hamburger menu
- Hero section with call-to-action buttons
- Services section with four service cards
- Portfolio section showcasing creative projects
- Contact form with client-side validation and submission confirmation
- Dark and light theme toggle
- Responsive design for desktop, tablet, and mobile
- Hover effects, smooth scrolling, and interactive elements
- SEO metadata
- Optimized images using Next.js Image component

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/vishwa0411/creative-agency.git
```

### 2. Navigate to the Project Folder

```bash
cd creative-agency
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

http://localhost:3000

## Production Build

To create an optimized production build:

```bash
npm run build
```
